# lys-desktop

The packages the lys desktop's [shell](https://github.com/stubbedev/lys-shell),
[login](https://github.com/stubbedev/lys-login) and
[settings](https://github.com/stubbedev/lys-settings) share: the config and its
schema, theming, translations, shared widgets and the clients of the desktop's
system services. It builds on [lys-ui](https://github.com/stubbedev/lys-ui) and
[lys-lib](https://github.com/stubbedev/lys-lib).

```sh
go get github.com/stubbedev/lys-desktop@latest
```
